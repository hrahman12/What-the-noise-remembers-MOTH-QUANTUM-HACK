# Credits

## The machine and the proof

- **Heiner Marxen & Jürgen Buntrock**, "Attacking the Busy Beaver 5", *Bulletin of the EATCS* 40
  (February 1990), pp. 247–251. The 5-state champion comes from their Table 1, entry 1 (47,176,870 steps,
  4,098 ones). Author's HTML rewrite: https://turbotm.de/~heiner/BB/mabu90.html
  Their table is written with L and R swapped relative to the bbchallenge string we use
  (`1RB1LC_1RC1RB_1RD0LE_1LA1LD_1RZ0LA`). It is the same machine mirrored, so our tape grows to the left.
- **The bbchallenge Collaboration** (with J. Blanchard, D. Briggs, K. Deka, N. Fenner, Y. Forster,
  G. Georgiev, M. L. House, R. Hunter, Iijil, M. Kądziołka, P. Kropitz, S. Ligocki, mxdys,
  M. Naściszewski, savask, T. Stérin, C. Xu, J. Yuen, T. Zimmermann), "Determination of the fifth Busy
  Beaver value", arXiv:2509.12337 [cs.LO] (2025). It proves S(5) = 47,176,870 with a Coq-verified proof,
  first announced in 2024. https://arxiv.org/abs/2509.12337
- **Pascal Michel**, "Busy beaver competition and Collatz-like problems", *Archive for Mathematical
  Logic* 32 (1993), pp. 351–367. Background on the Collatz-like behaviour of busy beaver champions.
- **bbchallenge wiki**, "5-state busy beaver winner",
  https://wiki.bbchallenge.org/wiki/5-state_busy_beaver_winner (CC BY 4.0, per the page footer).
  `simulate.py` uses its high-level rules (g(3k) → g(5k+6), g(3k+1) → g(5k+9), g(3k+2) halts) only to
  predict the 15 phrase boundaries. Each one is then checked against the simulated tape.

## Quantum engine

- **Moth Quantum Atlas, blur-midi-v1 ("Blur Jazz")**, run on Atlas's classical statevector simulator.
- **QuantumBlur** (qiskit-community; copyright IBM, Apache License 2.0 per the file header),
  https://github.com/qiskit-community/QuantumBlur. Its `make_grid` gives the qubit rule
  ⌈log₂ Lx⌉ + ⌈log₂ Ly⌉ that we use to compute how many qubits a piano roll needs.

## Software

numpy, scipy (`fftconvolve` for the WAV reverb), mido (MIDI I/O), Pillow (figures), Node.js (page
tests). The page synthesises sound with the browser's Web Audio API and loads no external scripts.
Its pixel-art scene uses the project's shared `common/inksprite.js` helper.
Fonts: Geist and IBM Plex Mono from Google Fonts (SIL Open Font License).

## Data

No third-party data, audio or images. The machine's run is computed by `simulate.py` (and again in
the browser). Every MIDI, WAV and image here was generated by the code in this folder or downloaded
from the Atlas jobs listed in PARAMS.md.

The pixel-art cast (the beaver, its hard hat and letters, logs, the lodge, trees and effects in
`web/sprites.json`, and the mascot `web/img/mascot.png` rendered from it) is original art made for this piece.
